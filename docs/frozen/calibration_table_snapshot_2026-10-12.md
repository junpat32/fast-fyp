# Calibration table: real-world numbers behind the FAST generator

Status: DRAFT (2026-10-09, research pass 1 by Claude). Values marked **TODO** or
**VERIFY** must be completed or checked by Patrick against the **primary source**
(DOSM, BNM, PIDM, KWSP, World Bank, PTPTN) before `generator_spec.md` is committed
(task T-01).

## Rules

1. Every generator parameter is either **Calibrated** (has a primary source) or an
   **Assumption** (a design choice that is tested across a range). Nothing goes in
   unlabelled.
2. Cite the primary source with a page or table number. A news article is only a
   pointer to the primary source, never the citation itself.
3. Record the population mismatch in "Caveat" (e.g. household vs individual,
   gross vs net, employees only).
4. If a value changes, update this file and the `generator/config.yaml`
   value in the same commit.
