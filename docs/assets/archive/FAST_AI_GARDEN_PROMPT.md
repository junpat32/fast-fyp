# FAST AI Garden Progression Asset Prompt

Use this prompt with an image-generation model.

---

Create a high-quality transparent PNG isometric pixel-art asset sheet for the **long-term outdoor progression system** of a mobile financial gamification game called **FAST**.

## Art Direction

- match the same visual style as the FAST starter-apartment assets
- 2D isometric pixel art
- consistent 2:1 isometric perspective
- designed to visually fit a 64 × 32 isometric tile grid
- clean, cozy, colorful but not childish
- suitable for smartphone screens
- subtle tropical Malaysian atmosphere
- consistent lighting, scale, pixel density, outlines, and shading
- transparent background
- every object isolated
- generous spacing
- no overlapping assets
- no people
- no text
- no labels
- no logos
- no UI
- no watermarks
- no full environment scene

Do not generate terrain tiles, floor tiles, exact path-grid tiles, structural fences, or other dimension-critical modular geometry. Those are generated separately using code.

## Purpose

These assets visually represent long-term financial progress.

The user's apartment remains the main hub, while a small outdoor garden beside or in front of the apartment gradually becomes more attractive over time.

The garden must support many combinations rather than only three fixed complete scenes.

---

# Growth Assets

## Tree Progression

Create separate isolated sprites for:

1. planted seed / tiny mound
2. tiny sprout
3. small sapling
4. young tree
5. medium healthy tree
6. mature tree
7. especially healthy or flowering mature tree

Keep each stage clearly related to the previous one.

---

## Flower Progression

Create:

- tiny flower sprouts
- small flower cluster
- medium flower cluster
- full healthy flower cluster
- richer flowering cluster
- several compatible color variations

Use flowers appropriate to a warm tropical environment.

Subtle hibiscus- or bougainvillea-inspired forms are welcome without becoming botanically literal.

---

## Shrubs and Plants

Include:

- small shrub
- medium shrub
- fuller decorative shrub
- tropical leafy plant
- small flowering bush
- potted outdoor plant
- decorative planter with greenery
- simple herb planter

---

# Long-Term Unlockable Decorations

Include:

- simple wooden bench
- improved garden bench
- small garden lamp
- decorative outdoor lantern
- bird bath
- planter boxes
- decorative stones
- garden arch
- small outdoor table
- outdoor chair
- mailbox
- bicycle parking rack
- simple decorative fountain

These should remain believable for a modest apartment garden.

---

# Progression Philosophy

The assets should support at least three broad progression phases:

## Starter

- sparse
- minimal greenery
- tiny plants
- almost empty outdoor area

## Growing

- flowers
- shrubs
- young tree
- some decorations
- visibly improving garden

## Flourishing

- mature tree
- healthy plants
- richer flowers
- attractive decorations
- welcoming garden

However, do not create only three complete garden scenes.

Create **modular isolated assets** so the game can support many garden levels by combining different unlocks.

---

# Malaysian Context

Use subtle tropical elements such as:

- warm-climate foliage
- hibiscus-like flowers
- bougainvillea-inspired flowering plants
- tropical leafy plants
- occasional palm-like foliage

Do not make the garden:

- a farm
- a plantation
- a fantasy forest
- an oversized botanical garden

It should remain a believable small urban/suburban apartment outdoor area.
