# FAST AI Character Sprite Prompt

Use this prompt with an image-generation model.

---

Create a high-quality transparent PNG isometric pixel-art character sprite sheet for a mobile financial gamification game called **FAST**.

## Art Direction

- same pixel-art style as the FAST apartment and garden assets
- 2D isometric pixel art
- consistent 2:1 isometric world perspective
- designed to look natural in a 64 × 32 isometric world
- clean readable proportions suitable for smartphone screens
- friendly modern life-simulation aesthetic
- modest realistic proportions
- slightly stylized for readability but not exaggerated
- consistent lighting, outlines, pixel density, and scale
- transparent background
- no UI
- no text
- no names
- no logos
- no weapons
- no watermarks

---

# Selectable Characters

Create **6 distinct young-adult player avatars**.

Use varied:

- hairstyles
- hair lengths
- natural skin tones
- face shapes
- casual clothing combinations
- glasses and non-glasses options

Include a balanced variety of masculine- and feminine-presenting options.

Use subtle Malaysian multicultural urban context without caricatures or stereotypes.

---

# Clothing Direction

Characters should look appropriate for Malaysian students and young working adults.

Possible clothing:

- casual T-shirts
- polo shirts
- simple button-up shirts
- hoodies or light jackets
- jeans
- casual trousers
- modest skirts
- sneakers
- simple flats

Avoid:

- luxury fashion
- fantasy clothing
- military clothing
- exaggerated costumes

---

# Required Directions

For each character include idle sprites facing:

- down-right
- down-left
- up-right
- up-left

For each character include walking animations facing:

- down-right
- down-left
- up-right
- up-left

Use **4 walking frames per direction** if possible.

---

# Sprite Consistency Requirements

For every character:

- keep character height consistent
- keep body scale consistent
- keep feet aligned consistently between frames
- keep frame dimensions consistent
- keep perspective consistent
- keep the same lighting direction
- do not cut off feet, hair, arms, or accessories
- include sufficient transparent padding around each frame
- avoid pose drift between animation frames

Arrange the sprite sheet in clean, predictable rows and columns so frames can be separated programmatically.

---

# Optional Extra States

If space permits, include:

- happy
- concerned
- celebrating
- thinking
- using phone
- sitting

These are secondary to the required idle and walking frames.

---

# Overall Character Direction

The characters should look like ordinary young adults living in the same FAST apartment world.

They should feel:

- approachable
- contemporary
- practical
- diverse
- believable
- suitable for a financial wellness / life-simulation app
