# Archive: AI image-model prompt drafts (not in use)

`FAST_AI_FURNITURE_PROMPT.md`, `FAST_AI_GARDEN_PROMPT.md` and `FAST_AI_CHARACTER_PROMPT.md` were
drafted as prompts for an image-generation model. On 2026-10-14 Patrick confirmed that all FAST art
stays **code-generated** (D-55, D-72), so these are kept only as a record of what was considered.

Their content lists were merged, corrected and given exact numbers in
`docs/assets/FAST_ASSET_SPEC_BATCH2.md`, which is the binding spec. Two items were dropped; see
`docs/assets/DROPPED_ITEMS.md`. Do not use these files to generate assets.
